# Demo documents

Everything in this folder is fictional test content. Do not use it as real scholarship guidance or claim the sample resume as your experience.

- `sample-resume-demo.pdf` and `.docx`: upload to Resume Analyzer to test real text extraction. Running analysis still requires your AI provider.
- `scholarship-guidelines-demo.pdf` and `.docx`: upload under Settings → Document knowledge to test real ingestion/embeddings. These describe the fictional Open Source Learners demo record.
- `01`–`10` text documents: demo scholarship guidelines generated by the seed.
- `11`–`30` text documents: demo job descriptions generated by the seed.

Text records are ingested by `npm run seed -w backend -- --with-embeddings`. The normal browser upload accepts PDF/DOCX only. The generated text deadlines are fictional; rerunning seed against a fresh database creates a new set of demo dates.

Regenerate the four PDF/DOCX test fixtures with:

```bash
node backend/scripts/generate-samples.js
```

This uses JavaScript and development dependencies only.
